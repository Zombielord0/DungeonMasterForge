Backup

Without an account, everything you make is saved only in this browser: characters, campaigns and their maps, homebrew, custom items, your monsters, favourite spells and map fog. Clearing your browser data, or using another computer, loses it. Keep a backup file somewhere safe.

Pictures you've imported as maps aren't in the backup. Keep them with Dungeon Map → Export → Map file.

Import a character

Bring in a character from the 5e Companion App or a fillable PDF character sheet. The Forge rebuilds it with its own rules, keeping the scores, skills, gear, spells and story. Anything the Forge doesn't know becomes homebrew.

In the 5e Companion App, open the character, then use Export or Share to save its file. For a PDF, use one you can still type into.

📥 Bulk import

Add many spells, feats, species, backgrounds, subclasses, magic items or monsters at once, for example from books you own. Fill in a template in Excel or Google Sheets, save it as CSV, then choose it here. A JSON file with the same columns works too.

Species and subclasses take several rows: one per trait, subrace or feature, each with the same name. Monsters take a whole stat block in one cell.
